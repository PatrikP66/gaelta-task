# Opíš, kde presne v Shoptete by si tento kód umiestnil (Admin → kde?)

- So Shoptetom som sa doteraz nestretol, ale kvôli tomuto zadaniu som sa prihlásil do administrácie a prešiel si editor. Na základe toho by som úpravy realizoval v sekcii Admin -> Vzhľad a obsah -> Editor.

- V Shoptete by som neupravoval celý HTML od nuly, ale existujúcu šablónu produktovej karty a do nej by som pridal daný element a úpravy, ktoré chcem docieliť
- CSS a JavaScript by som primárne vložil cez vstavaný editor v sekcii Vzhľad a obsah. Alternatívna možnosť je použiť Správcu súborov, kde si viem nahrať vlastné CSS/JS súbory a následne ich nalinkovať v sekcii Záhlavie (pred uzátvárajúcím tagom HEAD) alebo Pätička (pred uzátvárajúcím tagom BODY).
